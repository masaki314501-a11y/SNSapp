# Clipcraft 使い方マニュアル

> Clipcraft(クリップクラフト)は、スマホで撮った縦長の動画に、字幕・タイトル・効果音などを入れて、TikTokなどに投稿できるショート動画にする道具です。むずかしい編集はAIがやってくれるので、編集をしたことがない人でも使えます。

## まず1本作ってみる

初めての人は、ここだけ読めば1本作れます。途中の設定は、全部そのままで大丈夫です。

1. アプリのトップ画面で **「動画を作成する」** を押す。
2. **「動画を選ぶ」** を押して、編集したい動画を選ぶ。動画が出たら、右下の **「使う範囲を選ぶへ進む」** を押す。
3. 次の画面では何もせずに、下の **「見た目の手本へ進む」** を押す。
4. 次の画面でも何もせずに、左下の **「手本なしで進む」** を押す。
5. 一番下の **「AIで自動編集する」** を押して、画面を開いたまま5分ほど待つ。
6. 終わると「確かめてほしいこと」が出るので、完成の動画を見て、問題がなければチェックを付ける。
7. **「生成完了(強調する字幕を確かめる)」** を押す。
8. 次の画面では何もせずに、一番下の青いボタン( **「強調せずに編集画面へ」** か **「この内容で編集画面へ」** )を押す。
9. 編集画面が開いたら、右下の **「編集完了」** を押す。
10. 動画ファイルができるまで、画面を開いたまま1分ほど待つ。
11. **「ダウンロード」** を押して保存する。

> これで完成です。画面の上には「ステップ 1 / 7」のように、今どこにいるかが出ます。全部で7つの画面を順に進みます。

> このマニュアルは、アプリのトップ画面の「使い方マニュアルを見る」から、いつでも開けます。別のタブで開くので、編集中の画面はそのまま残ります。

## 用意する物

- 縦長(スマホを縦に持って撮った)の動画1本。200MBまで。
- スマホかパソコンのブラウザ(Chrome か Safari)。
- アプリを開く時のIDとパスワード。聞かれた時だけ必要です。管理している人に聞いてください。

## 最初に知っておく言葉

| 言葉 | 意味 |
| --- | --- |
| 字幕(テロップ) | 画面の下の方に出る、話している言葉の文字 |
| 左上のタイトル | 動画の最初から最後まで、左上に出しておく「何の話か」の一言 |
| 強調 | 大事な言葉の字幕だけ、色や帯を変えて目立たせること |
| クリップ | 動画を切れ目で分けた、一切れずつの部分 |
| タイムライン | 編集画面の真ん中にある横長の帯。左が動画の始め、右が終わりで、クリップが横に並ぶ |
| 寄り(ズーム) | 話している人に、グッと近づく演出 |
| 効果音・BGM | 効果音は文字が出る時に鳴る短い音(ポン、など)。BGMは後ろでずっと流れる音楽 |
| 書き出し | 編集した内容を、1本の動画ファイルにすること |

ほかの言葉は、一番下の「用語集」にあります。

## ステップ1 動画を選ぶ

**やること:** 編集したい動画を1本選びます。

1. トップ画面の **「動画を作成する」** を押す。
2. 点線の枠の **「動画を選ぶ」** を押し、スマホやパソコンの中の動画を選ぶ。
3. 動画と「長さ 〇秒」が出たら、右下の **「使う範囲を選ぶへ進む」** を押す。

![選ぶ前の画面](img/01.png)

![動画を選んだ後の画面](img/02.png)

**うまくいかない時**

- 違う動画を選んだ時は、左下の **「別の動画にする」** で選び直せます。
- iPhoneで撮った動画は、読み込む前に自動で変換するので、少し待つことがあります(1分の動画で30秒ほど)。

## ステップ2 使う範囲を選ぶ

**やること:** 前置きや撮り直しなど、使わない所を先に切ります。全部使うなら、何もせずに **「見た目の手本へ進む」** を押します。

細かい間や「えーと」はAIが後で切るので、ここでは大きくいらない所だけで大丈夫です。

![使う範囲を選ぶ画面](img/03.png)

**やり方(いらない所をまとめて消す)**

1. 青い「使う範囲」のバーを、消したい所だけ指(パソコンならマウス)でなぞる。
2. 出てきた **「この範囲を捨てる」** を押す。
3. 何回か撮った中から1回分だけ使いたい時は、使う所をなぞって **「ここだけ残す」** を押す。
4. 終わったら **「見た目の手本へ進む」** を押す。

> 赤い縦線は「今見ている位置」です。下の帯を押すと、その時間に移ります。捨てた所は、この後のAIの編集には使われません。

**ほかのボタン(使わなくてもよい)**

| ボタン | できること |
| --- | --- |
| 再生(▶) | 動画を再生・一時停止する |
| ここから使う | 赤い縦線より前を捨てる |
| ここまで使う | 赤い縦線より後ろを捨てる |
| クリップ分割 | 赤い縦線の位置で、動画を2つに切る |
| クリップ削除 | 選んだクリップを捨てる |
| 削除部分を復元 | 捨てた所を元に戻す |
| ↶ ↷(右上の矢印) | 1つ前の操作に戻す・やり直す |
| 全体・縮小・拡大 | 下の帯の見える幅を変える |

## ステップ3 見た目の手本を選ぶ(なくてもよい)

**やること:** まねしたい投稿があれば、そのスクショか動画を渡します。AIが色・文字の感じ・字幕の位置を、その雰囲気に寄せます。特になければ、左下の **「手本なしで進む」** を押します。

![見た目の手本を選ぶ画面](img/04.png)

1. **「手本の画像・動画を選ぶ」** を押し、スクショか動画を選ぶ(10個まで、まとめて選べます)。
2. AIが手本を読み取るまで、少し待つ。
3. **「自動編集へ進む」** を押す。

> コツ: 同じ人の投稿を何枚か入れると、たまたま1枚に写っていた色ではなく、その人のいつもの編集のクセをまねします。「工程ごとに編集する」で進める時も、ここで選んだ手本を一番優先して使います。

## ステップ4 AIで自動編集する

**やること:** 一番下の **「AIで自動編集する」** を押すと、AIが編集マニュアルの工程1〜14を、自動で順に進めます。設定は全部そのままで大丈夫です。

> **どれを押せばいい？**
> 初めてなら **「AIで自動編集する」** 。押して待つだけで、最後まで作ってくれます。
> 1つずつ結果を確かめながら作りたい時は **「工程ごとに編集する」** 。中身は同じ工程1〜14です。くわしくは[工程ごとの編集のページ](steps.html)を見てください。
> AIを使わずに自分で全部作りたい時は **「AIを使わず自分で編集する」** 。くわしくは[このページ](self.html)を見てください。

![自動編集の画面](img/05.png)

**待っている間**

今どの工程を進めているかが、一覧で出ます。5分ほどかかります。 **終わるまで、この画面を開いたままにしてください** (閉じると止まります)。やめたい時は **「自動編集をやめる」** を押します。

> 最後の工程14で、編集時のチェック項目を確かめます。AIの答えのぶれで直す所が見つかった時は、その工程から自動でやり直します(2回まで)。

**終わったら**

工程14のページが開き、「確かめてほしいこと」が出ます。

1. 上の動画を見て、問題がなければ「確かめてほしいこと」にチェックを付ける。
2. **「生成完了(強調する字幕を確かめる)」** を押す。ステップ5へ進みます。

![チェック項目の結果](img/13.png)

> 気に入らない所があれば、上の進み具合の点を押して、その工程のページを開き、 **「やり直す」** を押します。その工程から後ろが作り直しになります。

**設定(どれもそのままでよい)**

| 設定 | 何を決めるか |
| --- | --- |
| 左上のタイトル | 左上に出す言葉。空なら、AIが話の中身から決めます |
| 長さの上限(秒) | 短くしたい時だけ入れる。空なら動画の長さのまま。入れた時は、超えた分をAIが前置きや繰り返しの場面から外します |
| どこに出す動画か | TikTok投稿か広告か。文字が隠れない範囲のチェックが変わります |

## ステップ4のかわりに: 工程ごとに編集する

「AIで自動編集する」と同じ工程1〜14を、1つずつボタンで進める方法です。工程ごとに結果を確かめながら作れます。ステップ4の画面の **「工程ごとに編集する」** を押すと開きます。

![工程ごとに編集する画面](img/11.png)

進め方と、工程ごとの説明は、[工程ごとの編集のページ](steps.html)にまとめています。

## ステップ5 強調する字幕を選ぶ(なくてもよい)

**やること:** 目立たせたい字幕をタップして選びます。選んだ字幕だけ、帯・色・書体が変わり、効果音が鳴ります。何もしないなら、一番下の **「強調せずに編集画面へ」** を押します。

AIが強調を選んだ字幕は、最初から選ばれた状態で出ます。

1. 上の「強調の見た目」で、帯の有無・文字の色・書体・効果音を決める(選んだ字幕全部に使われます)。
2. 下の字幕の一覧で、強調したい字幕をタップする。右端が「ふつう」から「強調」に変わります。もう一度タップすると戻ります。
3. 字幕の左の▶を押すと、その場面を上の動画で確かめられます。
4. **「この内容で編集画面へ」** を押す。

![強調の見た目を決める所](img/14.png)

![字幕をタップして強調にした所](img/15.png)

> 「重大ワード」に言葉を入れると、どの字幕に出てきても、その言葉だけ選んだ色で少し大きくなります(例: 治療の名前)。

## ステップ6 編集画面で手直しする(なくてもよい)

**やること:** AIの編集を見て、気になる所だけ直します。直す所がなければ、右下の **「編集完了」** を押して次へ進みます。

![編集画面](img/16.png)

**画面の見方**

- 上: できあがりの見本。▶で再生できます。
- 真ん中: タイムライン。動画がクリップ(切れ目ごとの一切れ)に分かれて並んでいます。赤い縦線が今見ている位置です。
- 下: 「カット」「字幕・音声」「演出」「効果音」「BGM」「編集完了」のボタン。押すと、それを直す画面が下から出ます。

> 字幕や演出を直す時は、先にタイムラインで、直したい場面のクリップをタップして選びます。選んだクリップだけが直ります。

**やりたいこと別の直し方**

| やりたいこと | やり方 |
| --- | --- |
| 字幕の言葉を直す | 直したい場面のクリップを選ぶ → **「字幕・音声」** → 「クリップの字幕」の欄の文字を直す |
| 字幕の見た目(色・書体・位置・大きさ)を変える | クリップを選ぶ → **「字幕・音声」** → 「字幕の見た目」で選ぶ。全部の字幕をそろえる時は「この字幕の見た目を全クリップに使う」 |
| いらない場面を切る | **「カット」** → ステップ2と同じ操作で切る・捨てる |
| 人に寄る(ズーム) | クリップを選ぶ → **「演出」** → 「寄り(ズーム)を入れる」にチェック |
| 文字や画像を足す | クリップを選ぶ → **「演出」** → 「強調テキストを追加」か「画像を追加」 |
| 左上のタイトルや、映像の明るさを直す | **「演出」** → 「動画全体」 |
| 効果音を足す・消す | **「効果音」** → 「効果音を追加」。緑の帯が効果音です |
| BGMを付ける | **「BGM」** |
| 文章でAIに直してもらう | 右上の **「AIに頼む」** → 「3つ目の強調テキストをもっと大きく赤に」のように書いて **「頼む」** |
| 間違えた操作を戻す | 再生ボタンの右の **↶** |

![字幕・音声のタブ](img/17.png)

![演出のタブ](img/18.png)

![効果音のタブ(緑の帯が効果音)](img/19.png)

![AIに頼む](img/20.png)

> 「全クリップに使う」を押すと、AIが顔をよけるために動かした字幕の位置も全部そろいます。押した後は、字幕が顔にかかっていないか確かめてください。

> 編集の中身は、このブラウザに自動で保存されます。途中で閉じても、同じスマホ・パソコンで開けば続きからできます(別のスマホ・パソコンからは開けません)。

## ステップ7 書き出して保存する

**やること:** 編集した内容を1本の動画ファイルにして、保存します。

「編集完了」を押すと、この画面で書き出しが自動で始まります。20秒の動画なら1分ほどです。書き出しは使っているスマホ・パソコンの中で行うので、 **終わるまでこの画面を開いたままにしてください** 。

1. 書き出しが終わると、完成した動画が出る。▶で最後に確かめる。
2. 「保存するファイルの名前」を好きな名前に直す(そのままでもよい)。
3. **「ダウンロード」** を押す。iPhoneなら、開いた動画の共有ボタンから「ビデオを保存」で写真アプリに入ります。

![書き出しが終わった画面](img/21.png)

> 直したい所が見つかったら、左上の「‹」で編集画面に戻り、直してからもう一度「編集完了」を押します。下の「表紙を作る」では、投稿の一覧で最初に見える絵(表紙)も作れます。

## AIを使わず自分で編集する場合

ステップ4の一番下の **「AIを使わず自分で編集する」** を押すと、すぐに編集画面(ステップ6)に進みます。字幕も文字も空の状態から始まるので、次の順に作ると楽です。

1. **「字幕・音声」** の **「一括生成」** で、話している言葉から字幕をまとめて作る。
2. **「カット」** で、間や言い間違えを切って捨てる。
3. **「演出」** で、強調テキスト・画像・寄りを足す。
4. **「効果音」「BGM」** で音を足す。
5. **「編集完了」** で書き出す(ステップ7)。

> AIの自動編集は1回ごとに料金がかかりますが、このやり方なら字幕を作る分だけで済みます。

## 困ったとき

ほとんどは、画面に出た知らせのとおりにやり直せば直ります。それでも直らない時は、画面のスクショを撮って、管理している人に送ってください。

| こんな時 | こうする |
| --- | --- |
| 「この動画はこのブラウザでは読み込めない形式です」と出た | 撮影したスマホから(iPhoneならSafariで)動画を選び直す |
| 「動画の長さを取得できませんでした」と出た | 「長さの取得を再試行」を押す。だめなら別のブラウザで選び直す |
| 「ファイルサイズが大きすぎます(上限200MB)」と出た | 動画を短くするか、画質を下げて撮り直す |
| 自動編集が「工程〇で止まりました」と出た | 「もう一度自動編集する」を押す。終わった工程は残っているので、「工程ごとに編集する」から止まった工程の続きを進めてもよい |
| 「動画が見つかりません」「元の動画をこのブラウザで読み込めませんでした」と出た | 時間がたって動画が片付けられた可能性があります。ステップ1から同じ動画を選び直す |
| 「Gemini APIのチャージ残高がなくなりました」と出た | 管理している人に連絡する(AIの料金の支払いが必要です) |
| 書き出しが進まない・失敗する | 書き出し中は画面を閉じず、スマホをロックしない。失敗したら「もう一度試す」を押す。最新のChromeかSafariを使う |
| AIの編集が気に入らない | 気になる工程のページで「やり直す」を押す。編集画面の「AIに頼む」でも直せる |
| 途中で画面を閉じてしまった | 同じスマホ・パソコンで開き直すと、続きからできる |
| 画面を開くとIDとパスワードを聞かれた | 管理している人に教わったIDとパスワードを入れる |

> 使われずに7日たった動画は、容量を空けるために自動で片付けられます。久しぶりに開いた編集で動画が出ない時は、動画を選び直してください。

## 用語集

| 言葉 | 意味 |
| --- | --- |
| 字幕(テロップ) | 話している言葉をそのまま出す文字 |
| 強調した字幕(強調テロップ) | 帯・色・書体を変えて目立たせた字幕(ステップ5で選ぶ) |
| 強調テキスト | 字幕とは別に、画面に足す文字(項目名・数字・ツッコミなど) |
| 左上のタイトル | 動画の最初から最後まで左上に出しておく、何の話かの一言 |
| 冒頭の見出し | 最初の3秒だけ画面の真ん中に大きく出す一言。見る人の手を止めるため |
| 枠 | ランキングや「〇選」で、答えを埋めていく四角 |
| クリップ | 動画を切れ目で分けた、一切れずつの部分。タイムラインに横並びで出る |
| タイムライン | 編集画面の真ん中の帯。左が動画の始め、右が終わり |
| 寄り(ズーム) | 話している人にグッと近づく演出 |
| 効果音 | 文字が出る時などに鳴らす短い音(ポン、ドンなど) |
| BGM | 動画の後ろでずっと流す音楽 |
| AIナレーション | AIが読み上げる声。自分で話していない所に付けられる |
| 見た目の手本 | まねしたい投稿のスクショや動画。AIが色や文字の感じを寄せる |
| 手本 | この編集チームが過去に作った完成動画。AIに見せて、編集の参考にさせる |
| クセ帳 | 手本の完成動画から、工程ごとの編集のクセをまとめた物。工程8・10でAIに見せる |
| 工程 | 編集マニュアルの作業の一つ一つ(1〜14)。「工程ごとに編集する」で順に進める |
| セーフティゾーン | TikTokのボタンや説明文で隠れない、画面の内側の範囲。広告はもう少し狭い |
| 光の補正 | 映像の明るさ・コントラスト・彩度を整えて、人を明るく見せること |
| 書き出し | 編集した内容を、1本の動画ファイル(.mp4)にすること |
| 表紙(サムネイル) | 投稿の一覧で最初に見える絵 |
