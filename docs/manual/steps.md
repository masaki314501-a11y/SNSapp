# 工程ごとに編集する

> 編集マニュアルの作業(工程1〜14)を、1つずつボタンで進める方法です。まとめてAIに任せるより仕上がりのぶれが小さく、工程ごとに結果を確かめながら作れます。

**開き方:** ステップ4(AIで自動編集)の画面で、 **「工程ごとに編集する」** を押します。

![工程ごとに編集する画面](img/11.png)

## 進め方

1. 1つの工程が1ページになっています。ページの **「実行」** を押す。
2. 上の動画と、「何をしたか」の結果を見る。
3. 良ければ **「次の工程へ」** を押す。気に入らなければ **「やり直す」** を押す(その工程から作り直します)。
4. 工程14まで進んで、「確かめてほしいこと」に全部チェックが付くと、 **「生成完了」** を押せるようになる。押すとステップ5(強調する字幕を選ぶ)へ進みます。

> 「AI」の印がある工程は、AIの料金と数十秒の待ち時間がかかります。「前の工程へ」で前のページに戻れます。

## 工程14 チェック項目

編集時のチェック項目を確かめて、自動で満たした項目は出さず、 **「確かめてほしいこと」だけ** を出します。

- 目で確かめる項目には、チェック欄が出ます。見て問題がなければチェックを付けます。
- 直す必要がある項目には「要修正」と、どの工程をやり直すかが出ます。
- 光の補正は、顔の明るさを測って自動で行います。誤字・脱字は、AIが音声と見比べて候補を出します。

![チェック項目の結果](img/13.png)

> 目で確かめるのは、主に「企業イメージを損ねていないか」と、お客様から受け取った画像を使った時の著作権です。工程13のBGMは、商用で使ってよい曲を選んでから実行します。
