# 工程ごとに編集する

> 編集マニュアルの作業(工程1〜14)を、1つずつボタンで進める方法です。「AIで自動編集する」も同じ工程を自動で進めているので、こちらは1つずつ結果を確かめながら作りたい時に使います。

**開き方:** ステップ4(AIで自動編集)の画面で、 **「工程ごとに編集する」** を押します。

![工程ごとに編集する画面](img/11.png)

## 進め方

1. 1つの工程が1ページになっています。ページの **「実行」** を押す。
2. 上の動画と、「何をしたか」の結果を見る。
3. 良ければ **「次の工程へ」** を押す。気に入らなければ **「やり直す」** を押す(その工程から作り直します)。
4. 工程14まで進んで、「確かめてほしいこと」に全部チェックが付くと、 **「生成完了(編集画面へ)」** を押せるようになる。押すとステップ5(編集画面)へ進みます。

> 工程は、ステップ4「AIで編集」の中の作業です。画面の上に「工程 8 / 14」のように、今どの工程かが出ます。「AI」の印がある工程は、AIの料金と数十秒の待ち時間がかかります。「前の工程へ」で前のページに戻れます。

## 工程14 チェック項目

出す前に確かめる項目(チェック項目)を確かめて、自動で満たした項目は出さず、 **「確かめてほしいこと」だけ** を出します。

- 目で確かめる項目には、チェック欄が出ます。見て問題がなければチェックを付けます。
- 直す必要がある項目には「要修正」と出ます。直し方は次の「引っかかった時」を見てください。
- 光の補正は、顔の明るさを測って自動で行います。誤字・脱字は、AIが音声と見比べ、数文字だけの小さな誤りは自動で直します。大きく書き換える物は、候補として出します。
- 長さは、工程12で長さの上限を入れた時だけ確かめます。

## 引っかかった時(要修正が出た時)

前の工程に1つずつ戻らなくても、工程14のページのまま直せます。

1. **「引っかかった所を自動で直す」** を押す。直せる見込みのある工程から工程14までを、自動でやり直します(直らなければ2回まで繰り返します)。
2. 1つの項目だけやり直したい時は、その項目の下の **「工程〇からやり直す」** を押す。その工程から工程14までを自動で流します。
3. やり直しても変わらない項目には、「このままでも出せます」かどうかと、編集画面のどこで直せるかが書いてあります。見て問題がない項目は、左のチェック( **このままでよい** )を付ける。
4. 「広告で使えない言葉がないか」が出た時は、引っかかった言葉の下の欄で言い換えて **「この言葉に直す」** を押す。その場で直して、チェックし直します。根拠があってそのままでよい時は、左のチェックを付けます。

> 「要修正」と「確かめてほしいこと」の全部にチェックが付くか、直って消えると、「生成完了」を押せるようになります。

> 目で確かめるのは、主に「会社やお店のイメージを悪くする所がないか」と、お客様から受け取った画像を使った時の著作権です。工程13のBGMは、商用で使ってよい曲を選んでから実行します。
