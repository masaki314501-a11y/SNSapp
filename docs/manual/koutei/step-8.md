# 工程8 必要なオブジェクトを作成する

**やること:** このページの **「実行」** を押して、上の動画と結果を見ます。良ければ **「次の工程へ」** を押します。

**AIを使います**(料金と数十秒の待ち時間がかかります)

**何が起きるか**

AIが、左上のタイトルの言葉と、ランキングや「〇選」の動画なら枠の数を決めます。タイトルと枠の見た目(書体・色・縁取り・形・出方)も、AIが手本に合わせて決めます。位置と大きさは、字幕に重ならないよう自動で計算します。

AIに見せる手本は、この編集チームの過去の完成動画と、そこから工程ごとの編集のクセをまとめた「クセ帳」です。ステップ3で見た目の手本を選んでいれば、それを一番優先します。

**見る所**

タイトルの言葉が動画の中身に合っているか。枠の数が項目の数と合っているか。タイトルと枠の色・書体が手本に近いか。

**うまくいかない時**

タイトルの言葉や見た目は、編集画面(ステップ6)の「演出」→「動画全体」で直せます。見た目が手本とずれる時は「やり直す」を押すか、ステップ3で見た目の手本を選んでからやり直します。
