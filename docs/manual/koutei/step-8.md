# 工程8 左上のタイトルと、ランキングの枠を作る

**やること:** このページの **「実行」** を押して、上の動画と結果を見ます。良ければ **「次の工程へ」** を押します。

**AIを使います**(料金と数十秒の待ち時間がかかります)

**何が起きるか**

AIが、左上のタイトルの言葉と、動画の型に合わせて画面に置く物を決めます。ランキングや「〇選」の動画なら左に枠を縦に並べ、2つを比べる動画なら画面の下にカードを2枚並べます。割合・採点・手順などの動画では、話の中身に合った図(円グラフ・採点表・流れの図など)の土台を、AIが自由に描きます。枠や図が無くても伝わる動画には、何も置きません。タイトルと枠の見た目(書体・色・縁取り・形・出方)も、AIが手本に合わせて決めます。位置と大きさは、人と字幕に重ならないよう自動で計算します(図は、空いた所の中にAIが描きます)。この時点の枠・カードは空で、図は中身の入っていない土台だけです(図の土台は、完成した動画では工程10で足す最初の部品と一緒に出ます)。項目名は、字幕ができた後の工程10で、言った順に入れていきます。

AIに見せる手本は、この編集チームの過去の完成動画と、そこから工程ごとの編集のクセをまとめた「クセ帳」です。ステップ3で見た目の手本を選んでいれば、それを一番優先します。

**見る所**

タイトルの言葉が動画の中身に合っているか。動画の型に合った物が置かれているか(ランキングなら枠の数が項目の数と合っているか、比べる動画なら下にカードが2枚あるか、図なら話の中身に合った図か)。タイトルと枠の色・書体が手本に近いか。

**うまくいかない時**

タイトルの言葉や見た目、図の文字は、編集画面(ステップ5)の「演出」→「動画全体」で直せます。図の絵は、同じ所で画像として消したり動かしたりできます。見た目が手本とずれる時は「やり直す」を押すか、ステップ3で見た目の手本を選んでからやり直します。
