# 工程6 映像を拡大して、人の位置を整える

**やること:** このページの **「実行」** を押して、上の動画と結果を見ます。良ければ **「次の工程へ」** を押します。

**AIを使います**(料金と数十秒の待ち時間がかかります)

**何が起きるか**

AIが顔の位置を調べ、顔が画面の中央より少し上に来るよう拡大します。顔がもう十分高い時は拡大しません。

ステップ3で見た目の手本を選んでいる時は、手本の人物と同じ位置・同じ大きさに映るように拡大します(手本より大きく映っている時は、位置だけ合わせます)。

**見る所**

顔が画面の少し上(見た目の手本があれば、手本と同じ所)にあり、頭が切れていないか。
