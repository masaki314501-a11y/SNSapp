# 工程14 チェック項目を確かめる

**やること:** このページの **「実行」** を押して、「確かめてほしいこと」を見ます。全部にチェックが付いたら **「生成完了」** を押します。

**AIを使います**(料金と数十秒の待ち時間がかかります)

**何が起きるか**

編集時チェック項目を確かめます。光の補正(顔の明るさを測って自動)と、誤字・脱字の確認(AIが音声と見比べ、見つけた誤字は自動で直す)もここで行います。自動で満たした項目は出さず、確かめてほしい物だけを出します。どこに出す動画か(TikTok投稿か広告か)はこのページで選びます。

**見る所**

「確かめてほしいこと」に出た項目を見て、問題が無ければチェックを付ける。

**うまくいかない時(要修正が出た時)**

前の工程に1つずつ戻らなくても、このページのまま直せます。

1. **「引っかかった所を自動で直す」** を押す。直せる見込みのある工程から工程14までを、自動でやり直します(2回まで)。
2. 1つの項目だけなら、その項目の下の **「工程〇からやり直す」** を押す。
3. やり直しても変わらない項目や、見て問題がない項目は、左のチェック( **このままでよい** )を付ける。

全部にチェックが付くか、直って消えると、「生成完了」を押せるようになり、ステップ5へ進みます。
