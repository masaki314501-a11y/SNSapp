# 工程14 チェック項目を確かめる

**やること:** このページの **「実行」** を押して、上の動画と結果を見ます。良ければ **「次の工程へ」** を押します。

**AIを使います**(料金と数十秒の待ち時間がかかります)

**何が起きるか**

編集時チェック項目を確かめます。光の補正(顔の明るさを測って自動)と、誤字・脱字の確認(AIが音声と見比べる)もここで行います。自動で満たした項目は出さず、確かめてほしい物だけを出します。どこに出す動画か(TikTok投稿か広告か)はこのページで選びます。

**見る所**

「確かめてほしいこと」に出た項目を見て、問題が無ければチェックを付ける。「要修正」と出た項目は、書かれている工程をやり直す。

**うまくいかない時**

全部にチェックが付くと、「生成完了」を押せるようになり、ステップ5へ進みます。
