# 工程7 字幕の位置を決める

**やること:** このページの **「実行」** を押して、上の動画と結果を見ます。良ければ **「次の工程へ」** を押します。

**何が起きるか**

字幕を話す人の顎より少し下に、動画全体で固定します。顎の下に入らない時は画面の下に固定します。

ステップ3で見た目の手本を選んでいる時は、手本の字幕と同じ高さ・同じくらいの大きさにします。

手本から「型」を読み取れた時(工程6)は、字幕の高さ・大きさ・横の位置(ランキングの枠を避けて右寄りに出す等)・文字の色まで、型どおりにします。手本でふつうの字幕として一番多く出ている見た目を、ふつうの字幕にします。下に見出しやカードがある型では、字幕の下の端をそろえ、2行になる時は上へ伸ばします。

**見る所**

この時点ではまだ字幕の文字は入っていません。工程9の後に、顔と字幕が被っていないか確かめます。
