# 工程10 大事な言葉を、目立つ字幕に変える

**やること:** このページの **「実行」** を押して、上の動画と結果を見ます。良ければ **「次の工程へ」** を押します。

**AIを使います**(料金と数十秒の待ち時間がかかります)

**何が起きるか**

AIが強調したい言葉を選び、強調した字幕にします。選んだ理由も出ます。

ランキングや「〇選」の枠がある動画では、項目名を枠に入れていきます。比べるカードがある動画では、比べる2つの名前をカードに入れます。話が進んで費用・期間などを比べる時は、名前の下の行に、その話題での中身(「約100万円」など)を入れ、話題が変わるたびに入れ替えます。図がある動画では、話に合わせて図に部品(グラフの1切れ・点数・〇印など)を足していきます。どれも、その話をした時から最後まで出したままにします(何を入れたかも結果に出ます)。ただし図では、採点表の点数のように同じ場所に次の文字が出る時は、前の文字をそこで消して入れ替えます。図の土台は、最初の部品と一緒に出ます。

ふつうの字幕と強調した字幕の見た目(書体・色・縁取りか帯か)も、AIが手本に合わせて決めます。赤や青の文字に黒の縁取りのように、文字も縁取りも暗い色の時は、暗い服の上でも読めるよう、強調した字幕の縁取りを白にします。工程8と同じく、過去の完成動画・クセ帳・見た目の手本(選んでいれば一番優先)を見せます。色は白・黒のほかに3色まで、書体は2つまでに収めます。見た目の手本を選んでいる時は、手本と同じ見た目にします(色・書体の数も手本どおり。工程14で数が多いと出ることがあります)。強調した字幕は、ふつうの字幕と見て違いが分かる色にします。

手本から「型」を読み取れた時(工程6)は、字幕の見た目は型どおりにします。手本に強調する字幕の見た目が何種類かある時は、AIが字幕ごとに、手本でその見た目を使っている役割(選ばれた方の名前・問いかけ・締めの案内など)に合う物を選びます。AIは強調する字幕と、枠・カードに入れる中身だけを決めます。枠やカードの中が絵の手本では、項目に合う絵を画像の棚から選んで入れます(合う絵が無い項目は文字にします)。ランキングでは、手本と同じく、項目を言った時にまず大きく絵と名前を出し、少し後に枠へ動かして入れます。比べるカードでは、手本と同じく、カードが出た時から名前をカードの下に、その上に比べる物の絵を入れておき、カードの上には「今の話題」(「費用」など)の見出しを出します。選ばれた方に丸を付ける手本では、話題ごとに「こちらが良い」と言い切った所で、そのカードの絵に丸を出します(その字幕の間だけ)。最後の一言がある手本では、動画の終わりに出します(最後の一言と同じ高さにある見出しなどは、重ならないよう、その時に消します)。ランキングで、話した項目が工程8で並べた枠より少ない時は、項目の数に合わせて枠を並べ直します。

**見る所**

強調された言葉が、見る人に一番残したい言葉になっているか。枠・カード・図に入った中身と順番が、話している内容と合っているか(図の数字が、話した数字と合っているか)。字幕の色・書体が手本に近いか。

**うまくいかない時**

強調する字幕は、編集画面(ステップ5)で場面を選び、「字幕・音声」→「この場面の字幕の強調」で選び直せます。
