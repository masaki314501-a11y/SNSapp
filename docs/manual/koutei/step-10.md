# 工程10 大事な言葉を、目立つ字幕に変える

**やること:** このページの **「実行」** を押して、上の動画と結果を見ます。良ければ **「次の工程へ」** を押します。

**AIを使います**(料金と数十秒の待ち時間がかかります)

**何が起きるか**

AIが強調したい言葉を選び、強調した字幕にします。選んだ理由も出ます。

ランキングや「〇選」の枠がある動画では、項目名を枠に入れていきます。比べるカードがある動画では、比べる2つの名前をカードに入れます。図がある動画では、話に合わせて図に部品(グラフの1切れ・点数・〇印など)を足していきます。どれも、その話をした時から最後まで出したままにします(何を入れたかも結果に出ます)。ただし図では、採点表の点数のように同じ場所に次の文字が出る時は、前の文字をそこで消して入れ替えます。図の土台は、最初の部品と一緒に出ます。

ふつうの字幕と強調した字幕の見た目(書体・色・縁取りか帯か)も、AIが手本に合わせて決めます。工程8と同じく、過去の完成動画・クセ帳・見た目の手本(選んでいれば一番優先)を見せます。色は白・黒のほかに3色まで、書体は2つまでに収めます。

**見る所**

強調された言葉が、見る人に一番残したい言葉になっているか。枠・カード・図に入った中身と順番が、話している内容と合っているか(図の数字が、話した数字と合っているか)。字幕の色・書体が手本に近いか。

**うまくいかない時**

強調する字幕は、編集画面(ステップ5)で場面を選び、「字幕・音声」→「この場面の字幕の強調」で選び直せます。
