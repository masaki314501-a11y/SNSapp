# 工程9 字幕を入れる

**やること:** このページの **「実行」** を押して、上の動画と結果を見ます。良ければ **「次の工程へ」** を押します。

**AIを使います**(料金と数十秒の待ち時間がかかります)

**何が起きるか**

AIが話している言葉を書き起こし、言葉のまとまりごとに字幕を入れます。位置は工程7で固定した所です。

話すのが速くて読み切れない字幕は、意味を変えずに短くします(どう短くしたかが結果に出ます)。カットの切れ目が言葉の途中にある所は、同じ字幕を出したままにします。

**見る所**

字幕の言葉が話している言葉と合っているか。短くした字幕の意味が変わっていないか。顔と字幕が被っていないか。

**うまくいかない時**

聞き間違いは、編集画面の「字幕・音声」で直せます。
