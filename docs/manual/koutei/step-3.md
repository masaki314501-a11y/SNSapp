# 工程3 言い間違いや言葉に詰まった部分をカットする

**やること:** このページの **「実行」** を押して、上の動画と結果を見ます。良ければ **「次の工程へ」** を押します。

**AIを使います**(料金と数十秒の待ち時間がかかります)

**何が起きるか**

AIが、言い直す前の言葉や「えーと」「あのー」を見つけて切ります。切った所と理由が一覧で出ます。

**見る所**

切った所の一覧を見て、必要な言葉まで切られていないか。

**うまくいかない時**

必要な言葉が切られた時は「やり直す」を押します。何度やっても同じ時は、編集画面(ステップ6)の「カット」で戻します。
