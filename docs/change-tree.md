# 完全模倣 変更の樹形図

「手本の完全模倣」機能を、どこをどう直したら、手本にどれだけ近づいたかの記録です。
後から「どの直しが効いたか」を追えるように、また、効かなかった直しだけを選んで戻せるように残します。

## この記録の読み方

- **樹形図**: 直しを木の形で並べています。上の直しを土台にして、下の直しを足しています。
- **ノード**: 1つ1つの直しのことです。番号(EC-1 など)で呼びます。
- **状態**: 次の5つのどれかです。
  - まだ: まだ手を付けていない
  - 作業中: いま作っている
  - 良くなった: 手本と並べて、前より手本に近づいた
  - 悪くなった: 手本と並べて、前より手本から遠くなった
  - 戻した: 効かなかったので、取り消した(記録は消さずに残す)
- **手本と並べて確かめた結果**: 同じカット動画と同じ手本から作った動画を、手本と同じ秒数で上下に並べた絵にして、目で見比べた結果です。
  - 並べるのは、上から「手本」「今までの作り方(1123と同じ)」「完全模倣」の3段です。
  - 最初の6秒は1秒ごと、そのあとは3秒ごとに並べます。
  - 画面が大きく切り替わった回数(カットや寄り)も数えて、手本と比べます。
- **指示文**: AIに送る文章のことです。指示文を変えたノードには、変える前と変えた後の文章を全部のせます。どの文言が効いたかを、後から比べられるようにするためです。
- **試しに使う動画**: 次の2本です(素材は Downloads の「ツール生成動画」フォルダー)。
  - 日本と韓国の矯正治療の違い(手本: 矯正治療どちらがおすすめ)
  - 治したほうがいい症状ランキング(手本: こんな歯になりたいランキング)

## 樹形図

```tree
完全模倣(EC)
├─ [まだ] EC-1 土台: 完全模倣の置き場所・画面・ボタン(今の部品を読み込んで動かす)
│   └─ [まだ] EC-1.1 答えにつながる物(同じ素材の完成動画・答えに近い指示文の例)を見せない
├─ EC-2 テロップの色と出し方
│   ├─ [まだ] EC-2.1 色(ふつうの字幕・強調した字幕の、字の色・縁・帯)
│   ├─ [まだ] EC-2.2 出る時の動き
│   └─ [まだ] EC-2.3 出るタイミングと消え方(話の区切りに合わせる)
├─ EC-3 ミニタイトル(左上などのタイトル)の書体と色
│   ├─ [まだ] EC-3.1 書体の見分け
│   └─ [まだ] EC-3.2 色・帯・透け方
└─ EC-4 効果音
    ├─ [まだ] EC-4.1 過去の動画から「どんな場面に、どんな種類の音」の表を作る
    └─ [まだ] EC-4.2 新しい動画で、場面に合った音を付ける
```

## 出発点: 今までの作り方(1123と同じ)を手本と並べた結果

1124ツール生成動画(オフ・1123と同じ作り方)を、手本と並べて確かめた結果です。完全模倣は、ここから手本に近づけていきます。

| | 手本 | 今までの作り方 |
|---|---|---|
| 日韓: 長さ | 57.6秒 | 72.3秒 |
| 日韓: 画面の切り替わり(10秒あたり) | 3.1回 | 5.7回 |
| ランキング: 長さ | 109.9秒 | 70.5秒 |
| ランキング: 画面の切り替わり(10秒あたり) | 1.7回 | 4.1回 |

- どちらも、手本より画面の切り替わりがずっと多い(強調した字幕すべてに寄りを付けているため)。
- ランキングのタイトル: 手本はふつうのゴシックなのに、手書き風の書体になっていた。帯は手本がくすんだ黄色で少し透けているのに、鮮やかな黄色だった。
- ランキングの枠: 手本は5つで帯のすぐ下から並ぶのに、6つで小さめだった。
- ランキングの絵: 手本は項目を言った時(5.5秒)に右下に出るのに、2.5秒から出ていた。
- 日韓: 手本の止め絵の見た目(書体・色・カード・丸)は近いが、字幕は書き起こしのまま、寄りと効果音は強調した字幕すべてに同じ物が付いていた。
