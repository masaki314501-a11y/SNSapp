# 効果音の使い方の分析(完成動画18本)

2026-11-28 まとめ。いただいた完成動画18本で、どこで・どんな場面で・どんな効果音を使っているかを調べた結果と、AIに渡す指示文。

## 調べた動画

アプリの手本の完成動画16本(data/edit-examples/media/correct)と、見た目の手本2本(矯正治療どちらがおすすめ・こんな歯になりたいランキング)。

## 調べ方

1. 声とそれ以外の音を分け(Demucs)、BGMの拍ではない、急に大きくなる音を拾った(416か所)。
2. 撮ったままの動画(効果音が入っていない)が残っている6本は、同じ所に音があるかを比べ、本物の効果音(81個)と、撮影の時の物音など(38個)を見分けた。これを正解にした。
3. 416か所すべてで、音が鳴る直前と直後の画面を並べて、目で見て、画面で何が起きたかを記録した。
4. 響きの近い音どうしをまとめ、動画をまたいで同じ効果音のファイルを使い回しているかを見た。
5. 画面の出来事(強調の字幕・写真・見出しなど)をAIに全部書き出してもらい、そのうち何割で鳴らしているかを出した(AIの時刻は1秒単位で大まかなので、割合は目安)。

AIに音を聞かせて「ポン」「シュッ」などと答えさせる方法も試したが、ほとんど全部に「ポンッ」と答え、当てにならなかった。音の感じは、測った数字(高さ・長さ・雑音っぽさ)から書いている。

## いちばん大事な決まり

**効果音は、必ず画面の出来事とセットで鳴らす。** 本物の効果音81個のうち74個は、画面で何かが起きた瞬間に鳴っていた。ふつうの字幕が替わるだけの時は5個、画面の変化が無い時は2個だけ。

鳴らす出来事(本物81個の内訳。重なりあり):

| 出来事 | 数 |
|---|---|
| 強調の字幕が出る | 52 |
| 枠に数字・%・項目が入る | 19 |
| 話題の見出し・次の項目が出る | 14 |
| 写真・イラストが出る・替わる | 8 |
| 白黒などの特殊な画面・カット | 3 |
| 丸の印・選ばれた方を示す | 3 |
| 締めの案内 | 2 |

## 出来事ごとの鳴らす割合(目安)

画面の出来事をAIに全部書き出してもらい(18本で約540個)、そのうち効果音が1秒以内に鳴っていた割合。AIの時刻が大まかなので目安。

| 出来事 | 鳴らした割合 |
|---|---|
| 枠・番号・項目名・カードが出る | 78%(29/37) |
| 写真・イラストが替わる | 71%(41/58) |
| 寄る | 71%(5/7) |
| 話題の見出しが出る・替わる | 70%(39/56) |
| 写真・イラストが出る | 69%(20/29) |
| 冒頭の大きな見出しが出る | 67%(12/18) |
| 締めの案内が出る | 18本中12本(目で見た記録から) |
| 丸・バツなどの印が出る | 62%(8/13) |
| 寄りから戻る | 57%(4/7) |
| 強調の字幕が出る | 43%(110/253) |
| 撮影場所が替わる・白黒・特殊な画面 | 31%(9/29) |

つまり、見出し・項目・写真・枠のような「構成が進む出来事」は7割前後で鳴らし、強調の字幕は半分弱だけに鳴らす。

## 音の種類と使い分け

同じ効果音のファイルを、動画をまたいで使い回している。よく使う音(聞いて確かめられるように、代表のファイルを付ける):

| 音 | 感じ(測った値から) | 主に使う場面 | 使った回数 | 聞ける代表のファイル |
|---|---|---|---|---|
| 音0 | 低い「ボン」(約130Hz・0.4秒) | 何にでも使う万能の音。強調・枠に入る・見出し | 16本で56回 | public/audio/exact-sfx/80017ba0bfd08375eedefda0471779d5/cand02.wav |
| 音1 | 高めの澄んだ短い音(約2.1kHz・0.25秒) | 写真・イラストが出る、強調、次の項目 | 15本で39回 | public/audio/exact-sfx/80017ba0bfd08375eedefda0471779d5/cand87.wav |
| 音2 | 「ピコン」(約1.3kHz・0.2秒) | 見出し・次の項目が出る(ランキングの次の国など) | 10本で36回 | public/audio/exact-sfx/90a1729960dd97f21659c710222275f4/cand07.wav |
| 音3 | 少し雑音まじりの「ポンッ」(約650Hz・0.35秒) | 強調、判定(「向いている/向いていない」)の印 | 8本で15回 | public/audio/exact-sfx/90a1729960dd97f21659c710222275f4/cand61.wav |
| 音4 | 低めの「ポン」(約350Hz・0.4秒) | 強調、冒頭、特殊な画面 | 6本で10回 | public/audio/exact-sfx/901e4e4326431c649123b3db0ace81b9/cand04.wav |
| 音5 | ごく短い「カッ」(0.02秒) | 採点表に点数が入る | 3本で7回 | public/audio/exact-sfx/90a1729960dd97f21659c710222275f4/cand39.wav |
| 音8 | 明るくきらめく音(約5.8kHz) | 強調、丸の印 | 5本で7回 | public/audio/exact-sfx/80017ba0bfd08375eedefda0471779d5/cand91.wav |
| 音12 | 長めに伸びる澄んだ音(約2.6kHz・0.7秒) | 強調、締め | 6本で6回 | public/audio/exact-sfx/b65f19fa8e88295affb1ad0308d79a85/cand54.wav |

使い分けの傾向:
- **繰り返す出来事は、1本の中で毎回同じ音。** 見出しが替わる・次の項目が出る・項目の写真が出る・点数が入る、のように動画の中で何度も起きる出来事には、その動画で1つの音を決めて毎回それを鳴らす(例:国ランキングでは、次の国が出る9回のうち7回が同じ「ピコン」。歯の白さ別では、次の色が出る5回すべて同じ音)。
- **強調の字幕は、ほぼ毎回ちがう音。** 1本の中の強調9〜13個に対して、音の種類は6〜12種類(どの言葉にどの音を選ぶかの決まりまでは、まだ確かめられていない)。
- 次の項目・見出しが出る時は、短く澄んだ「ピコン」系(音1・音2)が多い。
- 点数・%など、枠に数字が入る時は、低い「ボン」(音0)か、ごく短い「カッ」(音5)。
- 判定・選ばれた方を示す印(丸・列に入る)は、判定の強調の字幕と同じ瞬間に出して、そこで鳴らす。

## 数と間隔

| 項目 | 値 |
|---|---|
| 10秒あたりの数 | 真ん中 2.1個(0.5〜3.0個)。トーク中心の動画は2〜3個、手術の記録のような動画は0.5個 |
| 間隔 | 真ん中 3.9秒。0.7秒より短い間隔はほとんど無い(4%) |
| 冒頭 | 18本中11本で、動画の頭(0.2秒まで)に鳴らす(冒頭の見出し・枠が出る時) |
| 締め | 18本中12本で、締めの案内(プロフィールのリンクへ)が出る時に鳴らす |

## 動画の型ごとのクセ

- **2つを比べる動画**(日本と韓国・削らないセラミックとラミネートベニア):話題の見出しが替わる時に「ピコン」系、選ばれた方に赤い丸が付く時に強調の音。項目ごとに「見出し→強調→丸」の順で鳴る。
- **ランキング・〇選**(国ランキング・こんな歯になりたい・症状ランキング):次の項目名(国の名前・芸能人の写真)が出るたびに同じ「ピコン」系。順位の発表(「4位」)と、写真が枠に入る時にも鳴らす。
- **採点**(ラミネートベニア治療採点):点数が採点表に入るたびに「カッ」(音5)。合計点が入る時も鳴らす。次の項目の写真が出る時に「ピコン」系。
- **向いている・向いていない**:項目のイラストが出る時に音1、判定の強調(「向いている」赤・「向いていない」青)とイラストが列に入る時に音3・音8。
- **手順の解説**(ラミネートベニアの5つの手順・神経を取った歯を長持ち):番号付きの手順(「①審査・診断」)が写真と出る時に鳴らす。その間の字幕では鳴らさないので、全体の数は少なめ(10秒に1個)。
- **ツッコミ・オチ**:白黒画面や、画面が縮む特殊な画面のツッコミ(「気絶しちゃう」「僕が芸能に疎い…」)で鳴らす。

## 鳴らさない所

- ふつうの字幕が替わるだけの所。
- 撮影場所が替わる・別の映像に切り替わるだけの所(鳴らすのは3割ほどで、鳴らす時はツッコミ・オチの特殊な画面)。
- 手術・処置の記録の映像の中(工程の見出し「局所麻酔」「歯肉切開」が出ても鳴らしていない。効果音はインタビューの場面だけ)。
- 0.7秒以内に続けて鳴らさない。

## AIに渡す指示文

効果音を置くAI(工程10・11や完全模倣)に、そのまま渡せる形。

```
効果音は、この編集チームの完成動画18本の決まりに合わせて置いてください。

1. 効果音は、画面で何かが起きた瞬間にだけ鳴らす。ふつうの字幕が次の字幕に替わるだけの所・画面が変わらない所では鳴らさない。
2. 鳴らす出来事(上ほど必ず鳴らす):
   - 枠・表に数字・%・点数・順位・項目名が入る(8割)
   - 写真・イラストが出る・替わる(7割)
   - 話題の見出しが替わる・次の項目(ランキングの次の順位・次の手順・次の候補)が出る(7割)
   - 冒頭の大きな見出し・枠が出る時(7割。動画の頭で鳴らす)
   - 締めの案内(プロフィールのリンクへ)が出る(7割)
   - 選ばれた方に丸などの印が付く(6割。判定の強調の字幕と同じ瞬間に)
   - 強調の字幕(全部ではなく、4割ほど。驚き・否定・称賛・ツッコミ・結論など、感情の強い言葉を優先)
   - 白黒など特殊な画面でのツッコミ・オチ(3割)
3. 繰り返す出来事(見出しが替わる・次の項目が出る・項目の写真が出る・点数が入る)は、その動画で1つの音を決めて、毎回同じ音を鳴らす。短く澄んだ「ピコン」系の音が多い。点数・数字が枠に入る時は、低い「ボン」か、ごく短い「カッ」。
4. 強調の字幕の効果音は、毎回同じにせず、いろいろな音を使い分ける(1本の中で6種類以上)。
5. 数の目安は10秒あたり2個前後(多くて3個)。間隔は4秒前後が基本で、0.7秒以内に続けて鳴らさない。
6. 撮影場所が替わるだけ・別の映像に切り替わるだけの所では、基本鳴らさない。手術・処置の記録の映像の間は(工程の見出しが出ても)鳴らさず、話している場面の強調にだけ鳴らす(全体で10秒に0.5個ほど)。
```

## 手本から効果音を拾う時の見分け方(ツールの改善)

正解のある119か所で試した、いちばん良い見分け方:音の始めの前後で画面が少しでも変わり、かつ、ほかの動画でも同じ響きの音が使われている音だけを効果音とする。残した70個のうち63個が本物(9割)。本物81個のうち63個を拾える。

- 「ほかの動画でも同じ音」が効くのは、この医院の編集チームのように同じ効果音を使い回す時。別の編集者の手本では、画面の変化だけで見分ける(残した89個のうち71個が本物、8割)。
- 締めの和音(日韓の手本の51.1秒)のように、BGMとよく似た音は拾えない。

## 確かでないこと

- 効果音の正解があるのは6本だけ。残りの12本は、画面の変化から効果音かどうかを判断した。
- 音の感じは数字から書いたもので、耳で聞いた感じとは違うことがある。代表のファイルを聞いて確かめてほしい。
- 出来事ごとの割合は、AIの時刻が大まかなため目安。
