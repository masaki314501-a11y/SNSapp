AI-2工程3

言い間違い・詰まりを探す

使うAI
Gemini Pro
一緒に送る物
今回の動画
添付した動画は、歯科医院の先生などが話しているショート動画の素材です。
次の範囲(元の動画の秒数)が、今使っている部分です:
1. 0.0秒〜21.4秒

この範囲の中から、編集で切るべき「言い間違い」と「言葉に詰まった部分」だけを探してください。
- 言い間違い: 言い直している所の、間違えた方(言い直す前)の言葉。言い直した後の正しい言葉は残す。
- 言葉に詰まった部分: 「えーと」「あのー」「えー」などの言葉にならない声、同じ言葉を繰り返してつかえている所。
- 話の内容として必要な言葉、言い直していない普通の言葉、間(無音)は切らない(無音は別の工程で切る)。
- 切る範囲は、その言葉の頭から終わりまでをできるだけ正確に、0.1秒単位で書く。迷う所は切らない。
- 見つからなければ空の配列で答える。

各項目に、切る理由(reason: 「言い間違い」か「詰まり」)と、その部分で言っている言葉(text)を書いてください。

AIが答えた範囲のうち、5秒以上の物は切りません(ルールR3-2)。切れ目はR3-3で静かな所へ寄せます。

(工程別のクセ帳 K-2 の全文)

(見た目の手本がある時: AI-9 の前置きと、手本のスクショ・動画、読み取ったメモ)

【ここから、今回編集する動画】
(今回の動画を添付)

添付した動画は、歯科医院などのショート動画の素材です。編集で画面に置く物(左上のタイトルと、ランキングの枠)を決めてください。
見た目と出方は、手本とクセ帳の編集チームの物に近づけてください。

1. title: 動画の最初から最後まで、画面の左上に出すタイトル。何の話かが一目でわかる短い言葉(全角16文字以内)。
   話の中に出てくる治療名・症状名を、話したとおりに1つ入れる。12文字を超える時だけ、意味の切れ目に「\n」を1つ入れて2行にする。
   「絶対」「最強」「No.1」「〇〇初」「大人気」のような誇大・比較の言葉は使わない。言っていない数字は入れない。
2. titleLook: タイトルの見た目。fontFamily(書体)・textColor(文字の色)・strokeColor(縁取りの色。付けないならnull)・
   bandColor(文字の後ろに敷く帯の色。敷かないならnull)・animation(出方)。
3. frameCount: ランキングや「〇選」のように、話の中で項目を順に挙げていく動画なら、その項目の数(2〜10)。
   ランキングの枠をその数だけ並べる。項目を順に挙げる動画でなければ0。
4. frameLook: 枠の見た目(frameCountが0なら、使わないので何でもよい)。borderColor(線の色)・borderWidthPx(線の太さ。2〜12)・
   fillColor(中の塗り。塗らないならnull)・cornerRadiusPx(角の丸み。0〜40)・numberColor(枠に付ける番号の色)・animation(出方)。

- 書体は次から選ぶ: Noto Sans JP(標準ゴシック) / M PLUS Rounded 1c(丸ゴシック(やわらか)) / Zen Maru Gothic(まる字(やさしい)) / Kosugi Maru(丸ゴシック(カジュアル)) / Zen Kaku Gothic New(モダンゴシック) / Dela Gothic One(極太インパクト) / Yusei Magic(マーカー太字) / Potta One(ポップな極太) / Reggae One(アウトライン・ポップ) / RocknRoll One(スタイリッシュ太字) / Mochiy Pop One(キュート・ポップ) / Noto Serif JP(上品な明朝体) / Shippori Mincho(繊細な明朝体) / Yomogi(手書き風) / Kaisei Decol(装飾的な明朝(エレガント))
- 出方は次から選ぶ: slide-up(下からスライドイン) / fade(フェードイン) / pop(ポップイン(拡大)) / zoom-in(ズームイン(縮小)) / highlight-sweep(マーカーで塗る) / shake-in(揺れて強調) / blur-in(ぼかしからくっきり) / slide-side(横からスライドイン) / flip-in(回転してめくれる)
- 色は #RRGGBB で書く。タイトル・枠・テロップを合わせた動画全体の色は、白・黒を除いて3色以内にする(チェック項目。白・黒は数えない)。
- 位置・大きさ・並べ方はツールの側で決めるので書かない。

reasonに、そう決めた理由(どの手本・クセ帳のどこを参考にしたか)を1〜2文で書いてください。

【変更】タイトル・枠の見た目(書体・色・縁取り・帯・形・出方)もAIが決めるようにしました。位置・大きさ・並べ方はR8-1〜R8-6で計算します。タイトルは20文字で切ります。枠の数は0〜10、線の太さは2〜12px、角の丸みは0〜40pxに収めます。

AI-5工程9

話している言葉を書き起こす

使うAI
Gemini Flash
一緒に送る物
今回の動画(元の動画まるごと)
添付した動画(全体の長さ: 00:21)の音声を、実際に話している
YouTube/TikTokの自動字幕のように、一文または意味のまとまりごとに区切って文字起こししてください。
話されている内容を漏れなく、すべて字幕にすることが最優先です。1つのクリップに複数の文を
詰め込んで要約したり、一部を省略したりしないでください。

# 出力ルール
- segmentsは動画の先頭(00:00)から末尾(00:21)までを
  隙間なく連続してカバーする配列。時系列順に並べる。個数の上限は120個(目安であり、
  実際に話されている文の数だけ作ってよい。最低1個)。
- 各要素のstartFromSecondsはそのクリップの開始秒(先頭は0)、durationInSecondsはその
  クリップの長さ(秒)。次のクリップのstartFromSecondsは前のクリップの終了時刻と一致させる。
- 1クリップは実際の字幕と同じくらいのテンポ(目安1〜6秒)にする。長い発話は複数クリップに
  分割してでも、全ての発話内容が字幕として画面に表示されるようにする。
- captionは各クリップの時間帯で実際に話されている内容をそのまま短くしたもの。
  全角18文字以内に収まるよう、意味を保ったまま簡潔にする(要約による
  内容の欠落は避け、文が長い場合はクリップを分割する)。内容を創作せず、実際に話されている
  言葉をもとにする。言い淀み(「えー」「あの」等)は取り除き、読みやすい書き言葉に整える。
- 発話が無い、または聞き取れない区間はcaptionを空文字列にする(その場合もクリップ自体は
  時間軸を埋めるために残す)。
- JSON以外の文字列は出力しない。

書き起こしをクリップに分ける決まりはR9-1〜R9-2です。動画の長さは、その動画の長さが入ります(上は21秒の例)。

(工程別のクセ帳 K-2 の全文)

(見た目の手本がある時: AI-9 の前置きと、手本のスクショ・動画、読み取ったメモ)

【ここから、今回編集する動画】

次は、ショート動画の字幕を順に並べたものです(番号: 字幕)。
1: (字幕1)
2: (字幕2)
3: (字幕3)

この中から、強調テロップ(基本の字幕とは違う、目立つ見た目の字幕)にしたい字幕を選んでください。
- ランキングや「〇選」のように項目を順に挙げていく動画では、項目名(順位・用語・治療名など、挙げていく物の名前)の
  字幕を、1つ目から最後まで全部選ぶ。項目の説明・答えの字幕は選ばない。
- それ以外の動画では、見ている人に一番残したい言葉が入った字幕(答え・数字・結論・本音やオチの一言)を、全体の3割までで選ぶ。
- 説明・つなぎ・前置き・締めのあいさつの字幕は選ばない。
- 効果を言い切る言葉(「絶対治る」「痛くない」など)を含む字幕は選ばない。

あわせて、字幕の見た目を、手本とクセ帳の編集チームの物に近づけて決めてください。
- baseLook: 基本テロップ(強調しない字幕)の見た目。fontFamily(書体)・style(outline=縁取り文字 / pill=色付きの帯の上に白い文字)・
  accentColor(outlineなら縁取りの色、pillなら帯の色)。
- emphasisLook: 強調テロップの見た目。fontFamily(書体)・textColor(文字の色)・bandColor(文字の後ろに敷く帯の色。敷かないならnull)。
- 書体は次から選ぶ: Noto Sans JP(標準ゴシック) / M PLUS Rounded 1c(丸ゴシック(やわらか)) / Zen Maru Gothic(まる字(やさしい)) / Kosugi Maru(丸ゴシック(カジュアル)) / Zen Kaku Gothic New(モダンゴシック) / Dela Gothic One(極太インパクト) / Yusei Magic(マーカー太字) / Potta One(ポップな極太) / Reggae One(アウトライン・ポップ) / RocknRoll One(スタイリッシュ太字) / Mochiy Pop One(キュート・ポップ) / Noto Serif JP(上品な明朝体) / Shippori Mincho(繊細な明朝体) / Yomogi(手書き風) / Kaisei Decol(装飾的な明朝(エレガント))
- 色は #RRGGBB で書く。動画全体の色は、白・黒を除いて3色以内にする(チェック項目。白・黒は数えない)。書体は基本と強調で2つまで(チェック項目)。
- タイトル・枠ですでに (工程8で使った色) を使っているので、字幕もこの色の中から選ぶと3色以内に収まる。

選んだ字幕の番号(picks)と、それぞれを選んだ理由(reasons。picksと同じ順)、見た目をそう決めた理由(lookReason)を答えてください。

【変更】基本テロップの見た目(書体・縁取りか帯か・色)と、強調テロップの見た目(書体・文字の色・帯)もAIが決めるようにしました。最後から2行目の「タイトル・枠ですでに…」は、工程8で使った色が入ります。字幕の一覧には、工程9で入れたテロップが番号付きで入ります。

AI-7工程12

長さを収めるために外す場面を選ぶ

使うAI
Gemini Pro
一緒に送る物
字幕の一覧と秒数(文字だけ)
次は、ショート動画の字幕を順に並べたものです(番号: 字幕 [その字幕の秒数])。今の長さは42.5秒です。
1: (字幕1) [2.4秒]
2: (字幕2) [3.1秒]

この動画を30秒以内に収めるため、外す字幕(その字幕の場面ごと外す)を選んでください。
- 外してよいのは、前置き・繰り返し・言い換え・話の本筋に関係ない脱線・締めのあいさつの重複。
- 外さないのは、動画のテーマを言う最初の一言・挙げていく項目(順位・用語・治療名など)とその答え・結論。
- 外す字幕の秒数の合計が、12.5秒以上になるように選ぶ。外すと話がつながらなくなる所は外さない。

外す字幕の番号(removes)と、それぞれの理由(reasons。removesと同じ順)を答えてください。

完成の長さが上限以内なら、AIには頼みません。上は42.5秒を30秒に収める時の例です。

AI-8工程14

誤字・脱字を探す

使うAI
Gemini Pro
一緒に送る物
今回の動画・画面に出す文字の一覧
添付した動画の音声と、次の画面に出す文字を見比べて、誤字・脱字を探してください(番号: [種類] 文字)。
1: [タイトル・枠の文字] (タイトル)
2: [字幕] (字幕1)

- [字幕]は話した言葉の書き起こし。聞き間違い(話している言葉と違う)・漢字の間違い・送り仮名の間違い・抜けている字・余計な字を探す。
  字幕は話した言葉を短くしてよいので、言い回しが違うだけ・言葉を省いているだけの物は誤りにしない。
- [タイトル・枠の文字]は話をまとめた言葉なので、話した言葉と違っていてよい。漢字・送り仮名の間違い、抜けている字・余計な字だけを探す。
- 専門用語・略語(DM・IVなど)は、話している言葉のとおりなら誤りにしない。
- 見つからなければ空の配列で答える。

誤りごとに、文字の番号(index)、誤りの部分(wrong)、正しい書き方(correct)、理由(reason)を書いてください。

枠の番号(1〜5などの数字だけの文字)は、一覧に入れません。

使うAI
Gemini Pro
一緒に送る物
見た目の手本(ステップ3で選んだスクショ・動画)
上は、これから編集する動画のために選ばれた「見た目の手本」(まねしたい投稿のスクリーンショット・動画)です。
この見た目に近づけて、別の動画をAIが工程ごとに編集します。そのAIに渡すメモを、次の見出しの順に書いてください。

### ジャンル・動画の型
### 工程7・9 基本テロップ(書体・色・縁取り・帯・大きさ・位置)
### 工程8 左上のタイトル(位置・書体・色・縁取り・帯・大きさ・出方)

### 工程10 強調テロップ(書体・色・帯・大きさ・何を強調しているか)

### ジャンル・動画の型ごとの組み立て
動画の目的や内容（型）に合わせて、画面構成を大きく以下のパターンに分類して組み立てます。

- **比較・2択型（例：AとBどちらが良いか）**
  画面下半分の左右（x:25%, x:75%付近）に、比較対象となる2つの「枠」または「カード」を配置します。解説の進行に合わせて、それぞれの枠内に文字や画像を出し、結論（勝敗や判定など）を枠の中や画面中央に表示します。
- **一覧・ランキング・手順・段階型（例：〇つの手順、〇選）**
  画面左側（x:15%〜25%付近）に、縦に複数の「枠」を並べます（項目数に応じて3〜10個）。進行に合わせて下から上、または上から下へ順番に枠の中に文字や画像を埋めていきます。現在解説している項目をハイライトする演出を多用します。
- **採点型**
  画面下半分に、複数の「枠」をグリッド状（例：上段3つ、下段3つなど）に配置します。進行に合わせて各枠に点数を埋めていきます。
- **グラフ型**
  画面下半分の中央（y:75%付近）に大きな「円グラフ」を配置します。話の進行に合わせて、グラフの各領域に対応する項目名と数値を表示していきます。
- **Q&A・シンプル解説型**
  専用の枠やグラフは置かず、人物とテロップを中心に構成します。必要に応じて画面中央（y:60%〜70%付近）に画像をポップイン（pop）で表示したり、解説用の全画面インサートを挟んで視覚的な変化をつけます。

※**注意点**：ビフォーアフター写真の比較、有名人の写真の使用、「圧倒的」「必ず治る」「〇分で終わる」などの誇大表現や絶対的表現は、医療広告ガイドラインに抵触する恐れがあるため、新しい動画の演出には持ち込まないでください。

### 工程6 人物の位置
基本のズーム倍率（scale）は1.0〜1.4程度に設定します。
人物の顔が画面中央より少し高め（y:40%〜50%付近）になるようにフォーカス位置（focusYPercent）を整えてください。
「一覧・ランキング・手順型」のように画面左側に枠を配置する型の場合は、人物が枠と被らないようにフォーカスを右寄り（focusXPercent: 70%〜80%程度）にずらして配置します。

### 工程7・9 基本テロップ
- **位置**: 画面下部、演者の顎より少し下から胸のあたり（y:60%〜90%付近）に配置します。画面下部に枠やカードがある場合は、それらを避けて上部（y:20%〜40%付近）や、最下部（y:80%〜90%）に配置します。
- **デザイン**: 書体は「極太インパクト」または「モダンゴシック」を使用します。文字色は白（#FFFFFF）または黒（#000000）を基本とし、背景に溶け込まないよう、文字色と反対の色の太い縁取り（stroke）を必ずつけます（例：白文字には黒縁、黒文字には白縁。太さは4〜8px程度）。帯（背景色）は基本的には敷きません。
- **動き**: 「ポップイン（pop）」または「下からスライドイン（slide-up）」で表示します。基本テロップは常に話し言葉に合わせてテンポよく切り替えていきます。

### 工程8 左上のタイトル
- **位置**: 画面上部の中央、または左寄り（x:25%〜50%、y:5%〜15%付近）に配置します。
- **デザイン**: 文字色は白（#FFFFFF）や黒（#000000）。視認性を高めるために、テーマカラー（例：#00BFFF、#20B2AA、#111111など）の帯（座布団）を敷くか、太い縁取りをつけます。書体は「極太インパクト」または「モダンゴシック」を使用します。
- **動き**: アニメーションは無し、または「フェードイン（fade）」で表示し、動画の最初から最後まで常に表示（keepUntilEnd: true）させ続けます。

### 工程8 ランキングの枠・一覧
- **位置と大きさ**: 左側に並べる場合は x:15%〜25%付近、幅（widthPercent）は20%〜35%程度。高さ（heightPercent）は項目数に合わせて10%〜15%程度に調整します。
- **形とデザイン**: 角丸の長方形（cornerRadiusPx: 10〜20程度）の図形（rect）を使用します。背景色は白（#FFFFFF）で不透明（fillOpacity: 1）にし、黒やグレーの枠線（borderColor、borderWidthPx: 4〜6）をつけます。
- **動き**: 空の枠は動画の最初から最後まで常に表示（keepUntilEnd: true）させておきます。
- **中身の動き**: 解説の進行に合わせて、該当する枠の位置にテキストや画像を「ポップイン（pop）」で重ねて表示します。
- **ハイライト演出**: 一覧や手順の解説では、現在話している項目を強調するため、対象の枠の上に「赤い太枠のみの図形（fillColor: null, borderColor: #FF0000, borderWidthPx: 8）」を「ポップイン（pop）」で一時的に重ねる演出を多用します。

### 工程10 強調テロップ
- **位置**: 基本テロップと同じ位置か、少し高めの目立つ位置。または、配置した枠やグラフのすぐ近くに出します。
- **デザイン**: 書体は「極太インパクト」や「ポップな極太」を使用し、基本テロップよりフォントサイズを大きく（fontSizePxを1.2〜1.5倍程度に）します。文字色は赤（#FF0000）、青（#0000FF）、黄色（#FFFF00）など、パッと目を引く色を使い、白や黒の太い縁取りをつけます。
- **動き**: 勢いをつけるため、必ず「ポップイン（pop）」で表示します。
- **強調する言葉**: 「ランキングの順位や点数」「割合（%）」「解説の結論（向いている/向いていない等）」「重要な項目名」を強調します。
- **頻度**: 1分程度のショート動画の中で、場面が切り替わるタイミングや結論を提示するタイミングで、5〜10回程度強調テロップを使用します。

### 工程11 効果音と寄り
- 効果音（sfx）は、強調テロップや画像がポップインするタイミングに合わせて付与します。
- **寄り（ズーム）**: 重要な結論を言う場面、自虐的なコメントやツッコミの場面など、感情が動くタイミングで一瞬だけ人物を少し拡大（scale: 1.2〜1.3）させて画面にメリハリをつけます。

### 色と書体の数(チェック項目)
- **色の数**: 動画全体で使用する色（テロップの文字色・縁取り・枠線・塗り・帯の色）は、白・黒を除いて **3色以内** に統一し、4色以上が混在しないようにしてください(白・黒は数えません)。
- **書体の数**: 動画全体で使用するフォントは、基本テロップ用と強調テロップ用の **最大2種類** までとし、3つ以上のフォントが混在しないようにしてください。

R14-2光の補正: 使う範囲を5等分した場面から、顔の部分の明るさの平均とばらつきを測る(顔が分からなければ画面全体)。
R14-3明るさは、平均が目標(顔なら150、画面全体なら125。255が真っ白)に近づくよう0.95〜1.35倍にする。目標との差が6%以内なら変えない。
R14-4明るさのばらつきが小さい(45未満)映像は、コントラストを1.08倍にする。彩度はいつも1.05倍。

工程14 チェックの基準

R14-5話す言葉とタイミング: どの字幕も、出ている間に声が0.2秒以上(短い字幕は長さの半分以上)出ていれば○。

R14-10冒頭空白: 最初のクリップで話し始めるまで0.3秒以内なら○。

R14-14BGM: 入っていない、または最後に0.2秒以上かけて音量を下げて終わるなら○。
R14-15【変更】色: 文字・枠・強調テロップの色が、白・黒(とそれに近い色)を除いて3色以内なら○(文字スタイルの色は数えない)。
R14-16フォント: 使っているフォントが2つ以内なら○。
R14-17光の補正: R14-2〜R14-4で補正していれば○。
R14-18効果音: 強調テロップがあり、すべてに効果音が入っていれば○。
R14-19長さ: R12-1の上限以内なら○。
