はじめに

Clipcraft は、撮った縦長の動画を1本選ぶだけで、AIが字幕・文字・効果音・寄り(ズーム)を入れて、SNS用のショート動画に仕上げてくれる道具です。全部で7つの画面を順に進めます。

用意する物

  • 縦長(スマホの縦向き)で撮った動画1本(200MBまで)
  • スマホかパソコンのブラウザ(Chrome か Safari)
  • 画面を開く時のIDとパスワード(聞かれた場合だけ。管理している人に聞いてください)

作業の流れ(画面の上に「ステップ 1 / 7」のように今どこかが出ます)

  1. 動画を選ぶ
  2. 使う範囲を選ぶ(いらない所を切る)
  3. 見た目の手本を選ぶ(なくてもよい)
  4. AIで自動編集する(2〜3分待つ)
  5. 強調する字幕を選ぶ(なくてもよい)
  6. 編集画面で手直しする(なくてもよい)
  7. 書き出して保存する

迷ったら、2・3・5・6は何もせずに「次へ進む」ボタンを押して大丈夫です。動画を選んで、AIに任せて、保存するだけでも1本できあがります。

このマニュアルは、アプリのトップ画面にある「使い方マニュアルを見る」を押せば、いつでも開けます(別のタブで開くので、編集中の画面はそのままです)。

ステップ1 動画を選ぶ

編集したい動画を1本選びます。

  1. トップ画面の「動画を作成する」を押す。
  2. 点線の枠の「動画を選ぶ」を押し、スマホやパソコンの中の動画を選ぶ。
  3. 動画と「長さ 〇秒」が出たら、右下の「使う範囲を選ぶへ進む」を押す。

間違えた動画を選んだら、左下の「別の動画にする」で選び直せます。iPhoneで撮った動画は、読み込む前に自動で変換されるので、少し(1分の動画で30秒ほど)待つことがあります。

ステップ2 使う範囲を選ぶ

前置き・撮り直し・言い間違えなど、使わない所を先に切ります。細かい間(「えー」など)はAIが詰めるので、ここでは大きくいらない所だけで大丈夫です。全部使うなら、何もせず「見た目の手本へ進む」を押します。

いらない所をまとめて消す(一番かんたん)

  1. 青い「使う範囲」のバーを、消したい所だけ指(マウス)でなぞる。
  2. 出てきた「この範囲を捨てる」を押す。何回も撮った中から1回分だけ使うなら、「ここだけ残す」を押す。

ボタンの意味

赤い縦線は「今見ている位置」です。下の帯を押すと、その時間に移ります。ここで捨てた所は、この後のAIの編集には使われません。

ステップ3 見た目の手本を選ぶ(なくてもよい)

まねしたい投稿があれば、そのスクショか動画を渡します。AIが色・文字の感じ・字幕の位置をその雰囲気に寄せます。特になければ、左下の「手本なしで進む」を押します。

  1. 「手本の画像・動画を選ぶ」を押し、スクショか動画を選ぶ(10個まで、まとめて選べます)。
  2. AIが手本を読み取るまで少し待つ。
  3. 「自動編集へ進む」を押す。

「工程ごとに編集する」で進める時も、ここで選んだ手本は、工程8(タイトル・枠)と工程10(字幕・強調)の見た目を決める時に、一番優先する手本としてAIに見せます。

コツ: 同じ人の投稿を何枚か入れると、たまたま1枚に写っていた色ではなく、その人のいつもの編集の癖をまねします。

ステップ4 AIで自動編集する

AIが動画を見て、切り方・タイトル・文字・画像・寄り・効果音までまとめて編集します。設定は全部そのままでよく、一番下の「AIで自動編集する」を押すだけで始まります。

選べる設定(どれも空のままでよい)

設定何を決めるか

動画の型ランキング・2択・解説など。「おまかせ」ならAIが中身を見て決める

AIへの要望(詳しい設定)「強調は黄色多め」など、そのまま文章で書く。手本より優先される

AIを使わずに自分だけで編集したい時は、一番下の「AIを使わず自分で編集する」を押します(このマニュアルの後の方で説明します)。

待つ間

押すと「AIが編集中…」に変わり、今どこまで進んだかに印が付いていきます。2〜4分ほどかかります。待っている間は別のアプリを使ったり画面を閉じたりしても大丈夫です。やめたい時は「自動編集をやめる」を押します。

結果を見て決める

終わると、同じ画面の下にAIの編集のまとめ(どんな構成にしたか、文字・効果音・寄りの数)が出ます。

一部だけ直してほしい「ここを直してほしい」に書いて「この内容で直す」

「ここを直してほしい」は、「3位の画像を入れ替えて」「20秒あたりの文字を小さく」のように、直したい所だけを書くと、ほかはそのままでそこだけ直します。

ステップ4のかわりに: 工程ごとに編集する

編集マニュアルの工程を、1つずつボタンで進める方法です。まとめてAIに任せるより仕上がりのぶれが小さく、工程ごとに結果を確かめられます。ステップ4の画面の「工程ごとに編集する」を押すと開きます。

進め方

  1. 上の「どこに出す動画か」(TikTok投稿か広告か)と「長さの上限」を決める。長さは、お客様の指定が無ければ30秒のままにする。
  2. 工程1から順に「実行」を押す。1つの工程が1ページになっていて、実行すると「何をしたか」が出、上の動画もその時点の状態に変わります。確かめたら「次の工程へ」で次のページへ進みます(「前の工程へ」で戻れます)。
  3. 気に入らない工程は「やり直す」を押す。その工程から作り直し、後ろの工程はやり直しになります。
  4. 工程14のチェックで、自動で確かめる項目がすべて○になり、目で確かめる項目にチェックを付けると、一番下の「生成完了」を押せるようになります。押すとステップ5へ進みます。

  • 工程2 話し始める前の不要な部分を削除する
  • 工程3 言い間違いや言葉に詰まった部分をカットする
  • 工程4 説明の間にある長い無音部分を削除する
  • 工程5 話の流れが自然になるように前後の映像をつなぐ
  • 工程6 映像を拡大し、人物の位置を整える
  • 工程7 テロップの位置を決める
  • 工程8 必要なオブジェクトを作成する
  • 工程9 テロップを入力する
  • 工程10 強調したい言葉を違うテロップに変換する
  • 工程11 強調テロップに効果音をつけ、少し人物を拡大する
  • 工程12 決めた長さに収める(長い時だけ)
  • 工程13 BGMを入れる(なくてもよい)
  • 工程14 チェック項目を確かめる

工程14 チェック項目

編集時チェック項目を確かめ、自動で満たした項目は出さず、「確かめてほしいこと」だけを出します。目で確かめる項目にはチェック欄が、直す必要がある項目には「要修正」と、どの工程をやり直すかが出ます。光の補正は、顔の明るさを測って自動で行います。誤字・脱字は、AIが音声と見比べて候補を出します。

目で確かめるのは、企業イメージを損ねていないかと、お客様から受け取った画像を使った時の著作権だけです。工程13のBGMは、「曲を選ぶ」で商用で使ってよい曲を選んでから実行します。

ステップ5 強調する字幕を選ぶ(なくてもよい)

目立たせたい字幕をタップして選びます。選んだ字幕だけ、帯・色・書体が変わり、効果音が鳴ります。何もしないなら「強調せずに編集画面へ」を押します。

AI(自動編集、または工程ごとの編集の工程10)が強調した字幕は、最初から選ばれた状態で出ます。外したい字幕をタップして「ふつう」に戻せます。

  1. 上の「強調の見た目」で、帯の有無・文字の色・書体・効果音を決める(選んだ字幕全部に使われます)。
  2. 下の字幕の一覧で、強調したい字幕をタップする。右端が「ふつう」から「強調」に変わります。もう一度タップすると戻ります。
  3. 字幕の左の▶を押すと、その場面を上の動画で確かめられます。
  4. 「この内容で編集画面へ」を押す。

「重大ワード」に言葉を入れると、動画のどの字幕に出てきても、その言葉だけ選んだ色で少し大きくなります(例: 治療名)。

ステップ6 編集画面で手直しする(なくてもよい)

AIの編集を見ながら、気になる所だけ直します。直す所がなければ、右下の「編集完了」を押して次へ進みます。

画面の見方

  • 上: 完成の見本。▶で再生できます。
  • 真ん中: タイムライン。動画が切れ目ごとの「クリップ」に分かれて並んでいます。赤い縦線が今見ている位置で、タップした所に移ります。
  • 下: 直したい物ごとのタブ。

下のタブでできること

タブできること

字幕・演出のタブは、選んでいるクリップだけが対象です。上の「クリップ 1 / 11」の左右の矢印か、タイムラインのクリップをタップして切り替えます。

字幕の見た目を変える

「字幕・音声」タブの「字幕の見た目」で、文字スタイルと「詳しい設定」(配色・見た目・フォント・位置・文字サイズ)を変えられます。変えると、選んでいるクリップの字幕だけが変わります。

  1. タイムラインで、見た目を変えたいクリップをタップする(複数選ぶと、その全部が変わります)。
  2. 「文字スタイル(選んだクリップ)」を押して、好きなスタイルを選ぶ。
  3. 色やフォントも変えたい時は、「詳しい設定」を開いて選ぶ。文字スタイルを選んだ後でも、フォント・位置・大きさは変えられます。
  4. 全部の字幕を同じ見た目にそろえたい時は、「この字幕の見た目を全クリップに使う」を押す。

AIは、顔に重ならないようにクリップごとに字幕の位置を変えていることがあります。「全クリップに使う」を押すと、その調整も外れて全部同じ位置になるので、顔にかかっていないか確かめてください。

工程ごとの編集(工程7)や自動編集で字幕を演者の顎の下に固定した時は、「位置」に「顎の下(固定)」が出ます。上・中央・下を選ぶと、そちらに変わります。

映像の明るさ(光の補正)

「演出」タブの「動画全体」で、映像の明るさ・コントラスト・彩度をつまみで変えられます。工程ごとの編集のチェック(工程14)をした時は、顔の明るさを測って自動で決めた値が入っています。「補正を外す」で元の映像に戻せます。

文章でAIに直してもらう

右上の「AIに頼む」を押し、「3つ目の強調テキストをもっと大きく赤に」のように書いて「頼む」を押すと、AIがそこだけ直します。自分で操作するより早いことが多いです。

間違えたら、再生ボタンの右の↶で戻せます。編集の中身はこのブラウザに自動で保存されるので、途中で閉じても続きからできます(別のスマホ・パソコンからは開けません)。

ステップ7 書き出して保存する

「編集完了」を押すと、この画面で動画の書き出しが自動で始まります。20秒の動画なら1分ほどです。書き出しは使っているスマホ・パソコンの中で行うので、終わるまでこの画面を開いたままにしてください。

  1. 書き出しが終わると、完成した動画が表示される。▶で最後に確かめる。
  2. 「保存するファイルの名前」を好きな名前に直す(そのままでもよい)。
  3. 「ダウンロード」を押す。iPhoneなら、開いた動画の共有ボタンから「ビデオを保存」で写真アプリに入ります。

直したい所が見つかったら、左上の「‹」で編集画面に戻り、直してからもう一度「編集完了」を押します。下の「表紙を作る」では、動画の場面にタイトルを大きく重ねた表紙(サムネイル)画像も作れます。

AIを使わず自分で編集する場合

ステップ4の一番下にある「AIを使わず自分で編集する」を押すと、AIの編集も強調の画面も飛ばして、すぐにステップ6の編集画面に進みます。字幕も文字も空の状態から始まるので、次の順に作ると楽です。

  1. 「字幕・音声」タブの「一括生成」で、話している言葉から字幕をまとめて作る。
  2. 「カット」タブで、間や言い間違えを切って捨てる。
  3. 「演出」タブで、強調テキスト・画像・寄りを足す。
  4. 「効果音」「BGM」タブで音を足す。
  5. 「編集完了」で書き出す(ステップ7)。

AIの自動編集は1回ごとに料金がかかりますが、このやり方なら字幕を作る分だけで済みます。

困ったとき

ほとんどは、画面に出た知らせのとおりにやり直せば直ります。それでも直らない時は、画面のスクショを撮って管理している人に送ってください。

こんな時こうする
「この動画はこのブラウザでは読み込めない形式です」と出た撮影したスマホから(iPhoneならSafariで)動画を選び直す
「動画の長さを取得できませんでした」と出た「長さの取得を再試行」を押す。だめなら別のブラウザで選び直す
「ファイルサイズが大きすぎます(上限200MB)」と出た動画を短くするか、画質を下げて撮り直す
「サーバーが入れ替わったため、編集の結果を受け取れませんでした」と出たもう一度「AIで自動編集する」を押す
「動画が見つかりません」「元の動画をこのブラウザで読み込めませんでした」と出た時間がたって動画が片付けられた可能性があります。ステップ1から同じ動画を選び直す
「Gemini APIのチャージ残高がなくなりました」と出た管理している人に連絡する(料金の支払いが必要です)
書き出しが進まない・失敗する書き出し中は画面を閉じず、スマホをロックしない。失敗したら「もう一度試す」を押す。最新のChromeかSafariを使う
AIの編集が気に入らない結果の画面で「別の案を作る」か、「ここを直してほしい」に書く。編集画面の「AIに頼む」でも直せる
途中で画面を閉じてしまった同じスマホ・パソコンで開き直すと、続きからできます
画面を開くとIDとパスワードを聞かれた管理している人に教わったIDとパスワードを入れる

使われずに7日たった動画は、容量を空けるために自動で片付けられます。久しぶりに開いた編集で動画が出ない時は、動画を選び直してください。
