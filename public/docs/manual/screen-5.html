ステップ5 編集画面で手直しする(なくてもよい)

やること: AIの編集を見て、気になる所だけ直します。直す所がなければ、右下の 「編集完了」 を押して次へ進みます。

画面の見方

  • 上: できあがりの見本。▶で再生できます。
  • 真ん中: タイムライン。動画が場面(切れ目ごとの一切れ)に分かれて並んでいます。赤い縦線が今見ている位置です。
  • 下: 「カット」「字幕・音声」「演出」「効果音」「BGM」「編集完了」のボタン。押すと、それを直す画面が下から出ます。

字幕や演出を直す時は、先にタイムラインで、直したい場面をタップして選びます。選んだ場面だけが直ります。

やりたいこと別の直し方

やりたいことやり方
字幕の言葉を直す直したい場面を選ぶ → 「字幕・音声」 → 「場面の字幕」の欄の文字を直す
字幕の見た目(色・書体・位置・大きさ)を変える場面を選ぶ → 「字幕・音声」 → 「字幕の見た目」で選ぶ。全部の字幕をそろえる時は「この字幕の見た目を全場面に使う」
いらない場面を切る「カット」 → ステップ2と同じ操作で切る・捨てる
人に寄る(ズーム)場面を選ぶ → 「演出」 → 「寄り(ズーム)を入れる」にチェック
文字や画像を足す場面を選ぶ → 「演出」 → 「文字を追加」か「画像を追加」
目立たせる字幕を変える場面を選ぶ → 「字幕・音声」 → 「この場面の字幕の強調」
左上のタイトルや、映像の明るさを直す「演出」 → 「動画全体」
効果音を足す・消す「効果音」 → 「効果音を追加」。緑の帯が効果音です
BGMを付ける「BGM」
文章でAIに直してもらう右上の 「AIに頼む」 → 「3つ目の画面に出す文字をもっと大きく赤に」のように書いて 「頼む」
間違えた操作を戻す再生ボタンの右の ↶

「全場面に使う」を押すと、AIが顔をよけるために動かした字幕の位置も全部そろいます。押した後は、字幕が顔にかかっていないか確かめてください。

編集の中身は、このブラウザに自動で保存されます。途中で閉じても、同じスマホ・パソコンで開けば続きからできます(別のスマホ・パソコンからは開けません)。
