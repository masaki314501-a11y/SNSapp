### 1. この編集者の編集の考え方
専門的な歯科知識を、視聴者が直感的に理解できる「ゲームやクイズのような視覚的フレーム」に落とし込んでポップに伝えることを最優先としています。無駄な間を徹底的に省いたタイトなテンポをベースにしつつ、時折見せる先生の本音や自虐ネタ、スタッフとの掛け合いではバラエティ番組のような演出（ズームや白黒化）を挟みます。真面目な解説と親しみやすさのバランスを取りながら、最終的に自然な流れで自院への来院（プロフィール誘導）へ繋げるのが特徴です。

### 2. 場面ごとの見せ方
- **質問者がテーマを投げかけた瞬間** → 画面上部に目立つ帯（背景色）付きのタイトルをポンと出し、動画の最後まで固定する。
- **複数の選択肢や手順が提示される場面** → 画面の下半分や左右に、空の枠やリストをあらかじめ配置し、全体像を先に見せる。
- **先生が項目名や答えを言った瞬間** → 空だった枠内にテキストをポップ音（pop）とともにポンと表示し、穴埋めしていく。
- **症状や治療法について解説する場面** → それを象徴するイラストや写真を、ポップ音とともに枠内や演者の横に表示する。
- **数値や割合を話す場面** → 「％」や「点数」のテキストを赤色や大きなフォントにして強調し、インパクトを与える。
- **先生が意外な回答や結論を言った瞬間** → テキストを大きく赤字にして、画面中央にドン（hit）という音とともに力強く出す。
- **先生が自虐ネタやぶっちゃけトークをした場面** → 先生の顔に一気にズーム（punch）してバラエティ感を出す(白黒化はこのツールでは使えないので、寄りと効果音で代える)。
- **インタビュアーが声だけでツッコミを入れる場面** → 少し小さめの文字で画面の隅に、「※〇〇」といった注釈風のテキストをそっと表示する。
- **特定の層や職業を挙げる場面** → （例：動画8の向いている人を語る動画では『アナウンサー』など）直感でわかるイラストを枠内にぽんと出す。
- **回答の正解発表や総括の場面** → 画面をパッと切り替え、全項目が埋まったリストを一覧で見せ、視聴者が振り返りやすくする。
- **「おすすめはどっち？」と結論を迫られる場面** → 両方の枠に「〇」のスタンプを付けたり、両者の良さを活かす折衷案のグラフィックを出す。
- **対立する概念を語る場面** → 色分けした枠（赤と青など）を左右に配置し、アイコンを各枠に振り分けて視覚的に対比させる。
- **患者のよくある勘違いを正す場面** → 「※そうじゃないと思う」といった補足テキストを、少し小さめに画面の隙間に表示する。
- **費用感について話す場面** → 本人が言った金額を、「自由診療」「目安」と添えて見やすく出す(金額だけを大きく強調しない)。
- **通院期間や回数について話す場面** → 「1年半」「最短2回」など、期間や回数を示す数字の文字色を変えて強調する。
- **順番に解説を進める場面** → 今話している項目の枠に、赤い太枠の図形(shapes)をその項目の話の間だけ重ね、今どこを話しているか示す。
- **歯の部位を説明する場面** → 画面の片側に部位のリストを出し、話している部位の画像を枠で囲んで強調する。
- **先生が笑ったり照れたりする場面** → ズームインして、先生の親しみやすい表情の変化をしっかり見せる。
- **締め（CTA）の場面** → 「プロフィールのリンクから！」というテキストを、明るい色（シアンや黄色など）で画面中央に大きく表示する。

### 3. 動画の型ごとの組み立て方
- **ランキング型**
  画面左側に1位〜10位などの空枠を縦に並べて固定。下位から順、または思いつく順に埋めていく。冒頭はテーマ発表、最後は全順位の正解一覧を表示して振り返り、そのままCTAへ流れる。
- **比較型（VS型） / 振り分け型**
  画面下部を2つに分割し、比較対象（赤と青の枠など）を配置。上から降ってきたテーマやアイコンを、解説しながら左右の枠に振り分ける。項目ごとに「〇」のマークを付けたりして勝敗を明確にする。
- **採点型**
  複数の評価項目（白さ、費用など）の空枠を画面に並べ、「/20」のような満点表示をあらかじめ置いておく。先生の解説に合わせて点数を埋め、最後に総合得点を赤字で大きく出す。
- **手順解説型**
  画面左側にステップごとの空枠を縦に並べる。今解説しているステップの枠を色付きの太枠などでハイライトし、画像やイラストを隣にポップアップさせて詳細を補足する。
- **割合（グラフ）型**
  画面下部に円グラフなどの図形を大きく配置。解説の進行に合わせて、グラフの各領域にテキスト（項目名と％）をポップさせていく。

### 4. 見た目の言葉
- **文字（字幕・タイトル）**：字幕（話している内容）は画面下部中央（または胸元）に配置。太めのゴシック体を使用し、白文字に黒の縁取り（アウトライン）をつけて視認性を高く保つ。タイトルは画面上部に固定し、背景に目立つ色（シアン、青、黒など）の座布団（帯）を敷く。
- **差し色の使い方**：強調したいキーワードや数字は、フォントサイズを1.5倍程度に大きくし、色を赤、黄色、シアンなどに変更する。
- **枠・カードの形**：角丸の長方形を多用。枠線のみ（少し太め）、または背景を白や半透明で塗りつぶす。比較時は赤と青などコントラストの強い色で枠を明確に分ける。
- **画像の出し方**：フラットなイラストや単体の写真を多用。イラストは枠の中央やテキストの上部に配置し、必ずアニメーション（popやfade）を伴って出現させる。
- **位置の決まりごと**：演者の顔周りは極力隠さない。下半分から左右にかけてを「情報表示エリア」として固定し、視聴者の視線移動を最小限に抑える。

### 5. 音とテンポ
- **効果音（SFX）**：新しい項目が枠に入る時、画像が出る時、点数が出る瞬間には軽快な「ポン（pop）」や「シュッ（swipe）」という音を鳴らす。重要な結論や意外な事実が明かされる瞬間には「ドン（hit / impact）」で強調する。
- **寄りのタイミング**：先生が個人的な意見を言う時、自虐ネタを言う時、核心を突く発言の時に、顔に一気にズームイン（punch）する。
- **間の詰め方**：「えー」「あのー」などのフィラーや、息継ぎによる無駄な間はジャンプカットで徹底的に排除し、常に先生がリズミカルに話し続けているようなタイトなテンポを作る。

### 6. この編集者がやらないこと
- 画面全体を長文のテキストで埋め尽くすこと（視覚情報過多の回避）。
- 複雑なトランジション（凝った場面転換）の使用（基本はシンプルなカット、フェード、スワイプのみ）。
- BGMの音量を上げすぎて、先生の解説の声が聞き取りづらくなること。
- 視聴者が「今何の話をしているか」迷うような画面構成（常に目次や枠、ハイライトで現在地を示す）。
